## 🛠️ Acciones Realizadas
1. **Refactorización de Autenticación**: Se eliminaron credenciales hardcoded; el POS ahora consulta dinámicamente los PINs y IDs de usuario (admin/waiter) desde el backend.
2. **Sincronización de Datos**: Se implementó `TablesModule` en el API y se actualizó el POS para consumir mesas reales de la base de datos, eliminando inconsistencias de IDs.
3. **Estabilización de Tests**: Se optimizaron los tests de Playwright para manejar latencias de red y animaciones de UI mediante esperas inteligentes y locatarios robustos.
4. **Hardening de Seguridad**: Se verificó el funcionamiento de los `RolesGuard` asegurando que solo los administradores puedan realizar tareas críticas.

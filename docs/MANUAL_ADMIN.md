# Manual del Administrador - MR-KING ERP

Como administrador, tienes el control total de las finanzas y la configuración del local.

## 1. Gestión de Turnos (Corte de Caja)
- **Apertura:** Al iniciar el día, ingresa el **Fondo de Caja** (dinero inicial para cambio).
- **Corte Z (Cierre):** Al final del día, ve a **CONFIGURACIÓN > CORTE (Z)**.
    - Ingresa el dinero físico total que hay en el cajón.
    - El sistema comparará lo vendido vs lo contado.
    - Si hay una diferencia, el sistema la reportará en el historial.

## 2. Control de Gastos
- Si necesitas sacar dinero de la caja para compras (ej. hielo, gas), usa el botón **+GASTO**.
- Ingresa el monto y la descripción. Esto se restará automáticamente del total al final del día.

## 3. Gestión de Menú y Precios
1. Ve al panel de **Administración de Productos**.
2. Puedes activar o desactivar productos según la disponibilidad.
3. **Precios:** El sistema utiliza un motor de precios protegido. Si cambias un precio aquí, se aplicará instantáneamente a todas las tablets.

## 4. Gestión de Mesas y Barra
- Puedes agregar nuevas mesas o bancos de barra desde el panel de **Configuración de Salón**.
- Recuerda que el sistema soporta hasta 30 mesas y 5 bancos por defecto.

## 5. Auditoría de Ventas
- En el panel principal, puedes ver el flujo de caja en tiempo real:
    - **INCOME:** Entradas por ventas de mesas o pedidos a domicilio.
    - **EXPENSE:** Salidas registradas por gastos de operación.

---
*Seguridad: Nunca compartas tu PIN de administrador. Este PIN permite realizar cortes de caja y modificar precios.*
